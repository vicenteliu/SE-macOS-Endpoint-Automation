# Disclosure

What this repository deliberately does not contain, and why. Published as an artifact
rather than kept as a checklist, because a checklist is skipped under deadline and a
missing file is not.

## Not here, on purpose

**No employer is named.** Not the one whose estate taught the author most of this, and not
any organisation whose specification informed the shape. Where scale matters to an
argument it appears as scale — *"a large enterprise Apple estate"* —
never as a place or a party.

**No reconstructible timelines.** An incident is a sequence of decisions, not a date with
a duration.

**No case studies.** No client, no internal project name, no before-and-after that
identifies a real environment.

**No rehearsal material.** The private half of this work includes spoken-delivery
acceptance and its recordings. None of it is here and none of it will be.

## The test that was applied

Not *"is this detail sensitive"* but **"does this detail, added to the others already on
the page, narrow the field?"** Specificity identifies where vocabulary does not. A figure
that is safe alone can stop being safe next to two others.

Keyword scanning is not a substitute for that question and was not used as one.

## Where the line actually sits

| Publishable | Stays private |
|---|---|
| The chain, hop by hop, and what breaks at each | Any environment it was learned in |
| Selection criteria between MDM products | Which one a given organisation ran, and how it was configured |
| The lab specification and its tier boundaries | Anything an employer would recognise as theirs |
| Marker-bounded capability — *"🔨 ADE enrolment at enterprise scale"* | The number's source, the org chart around it, the architecture underneath it |

## Direction of flow

Material moves **one way**: a finished artifact is de-identified and published outward.
This repository never imports from a private workspace, never cites a private file as
evidence, and every claim it makes stands on its own in publishable terms. The detailed
mapping of which private fact became which published sentence is itself private — putting
it here would undo the work it records.
